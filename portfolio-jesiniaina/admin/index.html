Connexion

Vos modifications sont enregistrées sur GitHub, puis Netlify met le site à jour automatiquement.

Comment obtenir mon jeton d'accès ?
  1. Sur GitHub : photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nom : « Portfolio admin » · Expiration : 1 an.
  3. Repository access : « Only select repositories » → choisir le dépôt du portfolio.
  4. Permissions → Contents : « Read and write ».
  5. Générer, copier le jeton (il commence par github_pat_) et le coller ici.
Le jeton ne donne accès qu'à ce dépôt. Ne le partagez avec personne.
